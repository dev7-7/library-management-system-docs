# Library Management System

## Introduction
The Library Management System is a web-based application used to manage
books, members, and book borrowing and returns in a library.

## Features
- Librarian login
- Add, edit, and delete books
- Member registration
- Issue and return books
- Search books by title, author, or category
- Track due dates and fines
- Generate library reports

## Technologies Used
- HTML
- CSS
- JavaScript

## Installation
1. Download the project.
2. Open the project folder.
3. Open index.html in a browser.

## Usage
1. Login as a librarian.
2. Add books and register members.
3. Issue a book to a member.
4. Record the book's return and any fine.
5. Generate the report.
